# 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

1. 首次运行初始化脚本，保管私有.env中的管理员密码；登录管理员后台。
2. 检查组织及IANA时区、角色权限、账号、类别和系统参数。工作人员应属于活动组织；非全部范围岗位需分配活动。
3. 新建活动草稿，录入中英名称、场地、售票、开始和退票时间。添加票种、价格、数量、座位前缀及每行列数；确认真实座位图后发布。
4. 观众注册或登录，在活动页选座并预留；票夹可以恢复原订单。免费票确认领票；演示票明确模拟付款；已配置STRIPE时跳转托管收银，返回后刷新票夹等待服务端确认。
5. 观众向工作人员出示票。检票员登录并选择授权活动，通过摄像头、JPEG/PNG图片（≤5MiB）或手输完整票码检票。仅“检票成功，可入场”可以放行；已使用、已作废、活动不符、无效或结果未知不能放行。
6. 本人或授权主办方发起未入场票退款。票立即作废；在退款与通知页面核对待办、原金额、模式和错误。仅收到退款成功确认才释放座位；已确认失败的任务需核对后重试，未知状态不创建新退款请求。
7. 票夹“隐私展示”隐藏二维码、备用票码和订单编号；出示或打印前切回“显示票码”。票夹打印按钮调用浏览器打印，可使用浏览器的保存PDF选项。不是服务器生成PDF或税务票据，没有物理打印机认证。
8. 账号停用、重置密码或组织停用会撤销旧会话。个人修改密码后重新登录。自定义观众角色只能有本人票夹权限，必须保留一个完整管理员及账号、角色、设置菜单。

常见问题：空活动列表表示未发布或当前岗位没有活动授权；座位不可选请刷新库存；过期订单需重新预留。返回收银页不等于已付款，查看票夹实际状态。邮件未配置不是发送成功。结果未知先刷新核对，不直接重复写入。

正式手机访问使用可达的HTTPS域名；localhost仅指访问设备自己。本机调试端口不能直接用于另一台手机。未授权摄像头时使用图片或手工方式。切换身份先退出，不保存QA密码。
