# TicketDesk 业务规则

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

单一经营主体支持多组织范围、多场活动。后台岗位必须同时拥有业务权限、组织范围和活动授权；观众只访问本人订单。公开活动资料不返回工作人员名单、持有人、密码或原始付款信息。本人票码只从本人票夹返回，后台订单不返回票码。

活动先草稿，配置票种及座位后发布；停售保留已有订单和票。首版按票种生成规则网格，不是自由拖拽的场馆图。每单一座，每张票独立身份，可多次建立不同座位订单；没有多座购物车。每场默认最多500座，可在1–500范围内调整，未验证大规模抢票容量。

预留35分钟，冻结服务端票价和币种，相同请求绑定本人和座位。到期或本人取消释放占用；相同旧请求不能自动生成新预留。停售不取消此前有效预留；Checkout必须仍在订单付款窗口内。Stripe Checkout要求至少30分钟过期窗口，因此预留后超过约5分钟未创建Checkout，应取消预留重新选座。

FREE零价票经本人确认直接出票，不执行银行付款。DEMO环境只能模拟付款和退款，界面、订单及报表标明模式。STRIPE环境禁用模拟付款，必须配置适格商户、HTTPS、Secure Cookie及支付和回调密钥。服务端建单绑定订单、会话、冻结金额及币种；收到原文验签且时间窗内的已支付事件才出票。不同通知但同一支付身份只记一次。前端返回页不能证明付款。

在线核销在活动开始前12小时至开始后24小时内开放；多名检票员同时检一票只能成功一次。已入场、作废、活动不符、伪造票码均拒绝。检票端需要服务端连接，断网或结果未知不能放行。二维码载荷不是普通浏览器网址，应由本系统检票页识别。

未入场票可在活动配置截止时间前申请全额退款。申请即作废，确认退款成功前座位不能转售。后台队列绑定原付款，未知结果使用同一幂等键重试；平台确认失败后，授权主办方核对并重试才生成新退款请求。迟到或重复收款的退款不能影响替代订单或另一张有效票。

已有任何预留历史后锁定活动币种及时间规则，不退回草稿；发布或有历史后锁定票价和座位布局，不能删除活动。类别停用不阻止维护已有活动；停用或换组织的旧工作人员在保存活动时移除失效授权，不重新授予权限。首次活动后组织时区锁定，活动展示按场地所属组织时区，时间编辑表单注明浏览器时区。

金额使用整数最小货币单位，首版支持CNY/USD/EUR/GBP/HKD。报表按活动、支付模式及币种分行，模拟金额不与真实金额混合；已核实迟到或多收款也属于收款记录，成功退款后相应扣减。报表不是税务凭证或银行自动对账。

邮件队列仅发本人订单和需登录的票夹链接，没有公开票码或PDF附件。未配置SMTP显示未配置，失败可重试；SMTP投递成功不代表邮件已进入收件箱。通知按首次出票排队，不发送营销信息。
